# Security Policy

## Reporting a vulnerability

Do not disclose sensitive vulnerability information, exploit details, secrets, or private information in public Issues, Discussions, or Pull Requests.

GitHub Private Vulnerability Reporting is the preferred channel once it is enabled for this repository. Until then, or when that channel is unavailable, send a private report to [github@yamarti.com](mailto:github@yamarti.com). Include only the information necessary to understand and reproduce the issue, and remove unrelated confidential material and secrets.

Reports are reviewed subject to limited maintainer capacity. No response time, remediation time, support level, acceptance, or outcome is promised.

## Scope

This repository currently contains an organizational framework rather than a production software implementation. Relevant reports may nevertheless concern repository configuration, documentation that could cause unsafe implementation, contribution or publication workflows, accidental information exposure, dependency or rendering mechanisms actually used by the repository, and future reference-implementation security when such an implementation exists.

General implementation-support requests, architectural consulting requests, and vulnerabilities in unrelated third-party products are outside this reporting channel.
